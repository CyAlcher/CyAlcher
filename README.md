## Hi, I'm Max 👋

**AI-Native Tool Builder** — I build tools that distill expert thinking into AI agents, so anyone can leverage world-class mental models inside Claude, Cursor, or any LLM-powered workflow.

### 🔭 What I'm Building

- **[mimeo-zh](https://github.com/CyAlcher/mimeo-main-zh)** — One command to clone an expert's public thinking into a plug-and-play `SKILL.md` / `AGENTS.md` for Claude Code & Cursor
- Exploring the intersection of **Agent Workflow × Chinese Knowledge Distillation × Domestic LLMs (DeepSeek)**

### 🚀 Featured Projects

| Project | TL;DR | Stack |
|---------|-------|-------|
| [mimeo-zh](https://github.com/CyAlcher/mimeo-main-zh) | Auto-distill public materials → generate ready-to-use Chinese SKILL.md | Python · DeepSeek · Claude Code |
| [ai_native_a_stock_agent](https://github.com/CyAlcher/ai_native_a_stock_agent) | AI-Native A-share stock analysis agent | Python · LLM · Agent Workflow |

### 🧠 What mimeo-zh Does in 30 Seconds

```bash
git clone https://github.com/CyAlcher/mimeo-main-zh.git
cd mimeo-main-zh && uv sync
uv run mimeo "段永平" --provider deepseek --format both
# → output/duan-yongping/SKILL.md  (ready for Claude Code)
```
